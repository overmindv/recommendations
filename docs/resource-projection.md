# Проекция задач и материалов

Проекция принимает только опубликованные метаданные. В ней нет текста
материалов, условий задач, ответов и тестов. Неполная запись сохраняет номер
версии, но удаляет ресурс из индекса тем. Неизвестное время не заменяется нулем.

- Tasks: фиксированный снимок и HTTP-журнал с `through`. Для перехода к
  следующей странице сохраняются `through` и верхняя граница текущей пачки.
- Content: сначала конечные offsets Kafka, затем снимок на одном watermark.
  События до watermark включительно уже учтены снимком. По каждому материалу
  применяется только более новая версия. Архив и снятие с публикации оставляют
  номер версии без метаданных; поздняя публикация не вернет материал.

Inbox, состояние ресурса и позиция чтения записываются в одной транзакции.
Реплика со старой позицией не может перезаписать новую. При чтении Kafka после
потери позиции или смены партиций строится новый снимок; до его завершения
активное поколение не меняется. Очистка затрагивает только снятые поколения,
не больше 500 записей и 500 событий за проход.

Клиенты владельцев умеют подтверждать точную версию пачкой до 100 пар.
Проекция не заменяет эту проверку. Фоновые процессы и фильтр выдачи еще не
подключены к запуску Recommendations.

## Проверки

На выделенную БД с именем, оканчивающимся на `_test`, сначала примени миграции. Для проверки с реальным
Kafka нужны отдельный брокер и права создания тестовых топиков.

```bash
go run ./cmd/recommendations migrate --dir migrations --dsn "$RESOURCE_PROJECTION_TEST_DSN" up
make resource-ctest
go test ./internal/projection/resources -run '^$' -bench BenchmarkResourceReplay -benchmem
```
