# Диагностика по учебной цели

Внутренний API принимает токен Recommendations и `X-User-ID` из проверенного
контекста Gateway. Все операции доступны только владельцу цели.

| Метод | Маршрут | Тело |
| --- | --- | --- |
| GET | `/v1/learner/goals/{id}/diagnostic` | Без тела |
| PUT | `/v1/learner/goals/{id}/diagnostic` | `{"goal_version":1,"budget_minutes":15}` |
| PUT | `/v1/learner/goals/{id}/diagnostic/skip` | `{"goal_version":1}` |

Запуск требует включенной проекции ресурсов. В бюджет входит до 20 минут,
но не больше недельного времени цели. Если бюджет не задан, берется меньший
из этих лимитов. Подбор читает до восьми коротких задач на тему, по целям и
активным прямым предпосылкам (до 32 тем всего). Tasks подтверждает текущие версии
и исключает задачи, уже знакомые студенту по истории решений или редактирования.
Неизвестное время не засчитывается. В сессии до четырех задач из разных тем.

Миграция индекса заполняет оценки для уже спроецированных задач. При обновлении
приостанови старые обработчики проекции, чтобы они не записывали версии без
заполнения нового поля. Миграции должны примениться до старта новых обработчиков.

Повторный запуск для той же версии цели возвращает существующую сессию,
не меняя бюджет, задания или срок. При запуске для новой версии цели
предыдущая сессия заменяется. При удалении цели сессия удаляется вместе с ней.
Сервер возвращает `no_tasks`, если подходящих заданий нет, и `expired` после срока.
Если закрепленная версия перестала быть доступной, сервер возвращает
`DIAGNOSTIC_TASK_UNAVAILABLE`, без подстановки другой задачи.

Пропуск доступен без связи с Tasks: статус `skipped`, базовый уровень `unknown`.
Конечный срок нужен для учета результатов, но сам по себе ничего не говорит о
знаниях. Прием подтвержденных результатов относится к отдельному этапу.

## Проверки

Примени миграции на выделенную БД с именем, оканчивающимся на `_test`.

```sh
make diagnostic-ctest
go test ./internal/projection/resources -run '^$' -bench BenchmarkDiagnosticCatalogProjection -benchmem
```

`diagnostic-ctest` использует `DIAGNOSTIC_TEST_DSN` и подменяет только HTTP-ответы
Tasks. Замер выборки использует `RESOURCE_PROJECTION_TEST_DSN` и 50 тысяч задач.
