# Ранжирование учебных ресурсов

`internal/ranking.Rank` принимает ограниченную выборку теории и задач с
проверенными версиями. Получение данных остается у вызывающего кода: каталог
подтверждает доступность и тему ресурса, учебная история определяет решенные
и недавние ресурсы. Пометка `DueReview` относится к точной версии задачи,
назначенной для [повторной проверки](retention.md).

Ресурс исключается, если тема вне текущего плана, версия недоступна, язык
не подходит, предпосылка не подтверждена, ресурс уже пройден или недавно
использован либо он не помещается в остаток бюджета. Ресурсы без языков
запуска (например, задачи с выбором ответа) языковой фильтр не ограничивает.
Отсутствующая предпосылка не считается подтвержденной. По каждой причине
возвращается счетчик, при нескольких причинах берется первая.

Баллы считаются целыми числами. Каждый сигнал умножается на вес из политики.

| Компонент | Сигнал |
| --- | --- |
| Разрыв с целью | `max(0, target_bps - score_bps)`; без достаточной выборки используется `unknown_gap_bps` |
| Сложность | 10 000 за совпадение уровня, 5 000 за соседний уровень, 0 за крайний; у теории 5 000 |
| Время | Доля времени, которое останется после ресурса, в шкале от 0 до 10 000 |
| Чередование | 10 000, если тип отличается от предыдущего ресурса; без предыдущего ресурса 0 |
| Повторение | 10 000 за назначенную задачу повторной проверки, если она прошла фильтры |

Уровень сложности выбирается по двум порогам. Если данных нет или выборка
недостаточна, базовый уровень `easy`. Итоговый балл равен сумме компонентов.
При равенстве сортировка идет по типу, ID ресурса, ID версии и ID темы.
Если ресурс относится к нескольким темам, остается самый высокий балл, а при
равенстве выбирается меньший ID темы. Две доступные версии одного ресурса
в выдаче считаются ошибкой входных данных.

Результат содержит версию алгоритма, `policy_version`, пороги, исходные веса и
баллы по каждому компоненту. При изменении весов или порогов меняется
`policy_version`. Вызов не выбирает веса по умолчанию и не меняет имеющийся
публичный подбор практики. При сохранении учебного плана нужно записывать
результат вместе с политикой, чтобы объяснение не менялось вслед за настройками.

Ограничения: 2 000 кандидатов, 64 темы и 128 позиций в результате. Бенчмарк
проверяет выдачу первых 20 позиций на верхней границе по входу.

```bash
go test -race ./internal/ranking
go test ./internal/ranking -run '^$' -bench BenchmarkRanking -benchmem
```
