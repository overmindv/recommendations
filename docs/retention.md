# Повторная проверка знаний

У каждой темы цели свой срок повторения: время последней независимой оценки
плюс настроенный интервал. Если оценки нет, тема остается `unknown`.
Просрочка не сбрасывает балл и не удаляет оценки. Для неактивной цели новые
проверки не назначаются.

Сервис рассматривает до 32 коротких задач по просроченной теме, без задач по
предпосылкам. Tasks проверяет, что версия опубликована и пользователь еще не
решал и не редактировал эту задачу. Бюджет одной проверки не выше 20 минут и
не выше недельного времени цели. Если подходящая задача не найдена в
проверенном наборе, тема остается просроченной.

Назначение закрепляет задачу и ее версию на семь дней. На тему и версию цели
хранится одно текущее назначение. При истечении срока можно запросить новую
проверку. Смена версии цели отменяет прежние назначения, но не затрагивает
оценки.

Оценка считается результатом проверки, если это первая независимая оценка
задачи данным студентом, по закрепленной версии и теме, начиная с момента
назначения и строго до конца срока. Результат включает вердикт, время и долю
веса задачи в теме. Провал дает ноль в числителе и сохраняет полный вес темы
в знаменателе [начальной оценки](mastery.md). Специальный балл за проверку
не начисляется: тот же результат учитывается один раз при пересчете.

## API

Оба маршрута внутренние. Нужны Bearer-токен gateway и доверенный `X-User-ID`.
GET считает сроки по текущей проекции оценок, не меняя сохраненный снимок.
В истории используется то же окно из 512 независимых сдач, что и в начальной
оценке. Если оно обрезано, ответ содержит `truncated: true`.

| Метод | Маршрут | Тело |
| --- | --- | --- |
| GET | `/v1/learner/goals/{id}/retention` | Без тела |
| PUT | `/v1/learner/goals/{id}/retention/{topic}` | `goal_version` и `due_at` из GET |

PUT возвращает `assigned` с закрепленной задачей или `no_new_task`.
Повтор с тем же сроком возвращает текущее назначение или его результат.
Устаревший срок или версия цели возвращают 409. Сбой Tasks возвращает 503
и не сохраняет пустое назначение.

## Включение

По умолчанию выключено. Нужны начальная оценка, прием учебных событий, проекция
каталога и миграция `202611190010` на базе Recommendations. Интервал задается
через `RECOMMENDATIONS_RETENTION_INTERVAL` в формате Go duration, от `1h`
до `8760h`, с точностью до секунды. Срок для пилота задается отдельно после
согласования.

```bash
go test -race ./internal/planner ./internal/httpapi ./internal/mastery -run 'Retention|DueReviews'
go test ./internal/mastery -run '^$' -bench BenchmarkRetentionRead -benchmem
```

Интеграционный тест использует `DIAGNOSTIC_TEST_DSN`, бенчмарк использует
`MASTERY_TEST_DSN`. Обе переменные должны указывать на выделенную базу с
суффиксом `_test` и примененными миграциями.
