# Учебный план на недели

`planner.BuildLearningPlan` собирает черновик по учебной цели, доступности
пользователя, подтвержденным оценкам и проверенным версиям ресурсов. Из
недельного времени вычитаются минуты, занятые другими активными целями.
Остаток ограничен бюджетом этой цели. Первая и последняя недели учитывают
только доступные дни в часовом поясе пользователя. Дедлайн включается в
расчет, а за его пределами время не выделяется.

Темы идут после своих предпосылок. Для недостающей темы нужны теория,
практика и отдельная задача для независимой проверки. Историю попыток
для этой задачи проверяет владелец каталога до вызова планировщика.
Ресурс нельзя использовать дважды в одном плане, даже если у него
несколько тем. Уже подтвержденная тема не получает повторную теорию.
По ней может остаться назначенная [повторная проверка](retention.md).
Ее ставим только на неделю, которая закончится до истечения назначения.

Если нужное подтверждение еще не получено, зависимый этап содержит
`requires_checks`. Это условия допуска, не результаты: назначенная
проверка не считается пройденной. Перед выдачей этапа нужно подтвердить
независимую оценку и порог предпосылки, указанный в политике плана.

На каждом этапе берется лучший доступный ресурс по
[ранжированию](ranking.md), который помещается в первую подходящую неделю.
В план записываются версия правил, веса и баллы выбранных ресурсов.
Если целиком разместить тему не получилось, ее этапы освобождают время,
а тема попадает в `unmet_outcomes` с причиной:

- `missing_resource`: нет подходящей теории, практики или проверки.
- `prerequisite`: не хватает предпосылки; ее ID есть в `blocked_by`.
- `time_budget`: ресурсы есть, но этап не поместился по времени.
- `plan_limit`: достигнут предел числа этапов.

Планировщик предлагает сократить охват, если часть тем не вошла. Более
поздний дедлайн появляется, только если повторный расчет в том же бюджете
и горизонте размещает все этапы. Это оценка расписания, не обещание освоения.

Пределы: 16 целевых тем, 64 темы вместе с предпосылками, 2 000 кандидатов,
26 недель и 128 этапов. В унаследованный подбор `practice-v3` этот расчет
не входит. Сохранение и обновление текущего плана остаются отдельной задачей.

```bash
go test -race ./internal/planner ./internal/ranking
go test ./internal/planner -run '^$' -bench BenchmarkBuildLearningPlan -benchmem
```
