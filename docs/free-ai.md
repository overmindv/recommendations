# Бесплатная AI-приоритизация практики

Реализовано: цель → агрегаты результатов и до 40 карточек → AI-порядок → серверная проверка → план. Остальные подходящие задачи дополняют горизонт обычным алгоритмом. AI не меняет prerequisites, бюджеты, результаты и версии задач. Материалы, автоматический выбор тем и диагностика знаний — следующий этап.

## Подключение

Достаточно одного провайдера; для переключения подключите несколько:

| Провайдер | Ключ | Переменные |
|---|---|---|
| Gemini | https://aistudio.google.com/apikey | GEMINI_API_KEY, GEMINI_MODEL |
| Groq | https://console.groq.com/keys | GROQ_API_KEY, GROQ_MODEL |
| OpenRouter | https://openrouter.ai/settings/keys | OPENROUTER_API_KEY, OPENROUTER_MODEL |

В локальном `infra/.env` задайте выбранные пары, `AI_ENABLED=true` и `AI_FREE_TIER_CONFIRMED=true`. Подтверждение означает: владелец проверил бесплатный тариф, доступность модели/региона и отключил платный биллинг. Gemini/Groq не позволяют надёжно определить тариф по ключу: код не гарантирует нулевой счёт при включённом платном аккаунте. OpenRouter принимает только конкретные модели с суффиксом `:free`, проверяет нулевые цены каталога и ограничивает цену маршрута нулём. Не используйте `openrouter/auto`.

Идентификаторы моделей выбирайте из актуальных каталогов кабинетов; они намеренно не зашиты. Для просмотра бесплатных кандидатов OpenRouter без ключа: `python3 recommendations/scripts/list-free-models.py` из корня workspace. Наличие в каталоге не гарантирует доступность или JSON-совместимость: проверьте preview после подключения.

После настройки пересоздайте recommendations и gateway обычным процессом запуска стека. Дефолт WRITE_TIMEOUT recommendations — 35s; не уменьшайте его ниже 27s. В Compose задано 35s. Gateway использует timeout recommendations 30s, HTTP write 45s (если переопределяли старые значения — обновите).

## Поведение и ограничения

- Порядок попыток: Gemini → Groq → OpenRouter; отсутствующие пары пропускаются. Не более трёх попыток по 8 секунд, затем обычный план с честным статусом.
- 429: пауза по Retry-After, без него час; 401/403 отключают провайдера до перезапуска. Отказ модели не обходится другим провайдером.
- Кеш 15 минут, до 1000 записей, изолирован по пользователю и полному входному snapshot: новые результаты/каталог меняют ключ. Одинаковые параллельные запросы объединяются.
- Не более 10 новых AI-запросов в час на пользователя, два одновременно на процесс. Кеш и лимиты в RAM: один экземпляр; перезапуск сбрасывает. Перед масштабированием нужен общий Redis и глобальные квоты.
- Наружу уходят цель, короткие публичные названия, агрегаты accepted/ошибок, эвристический уровень и локальные номера кандидатов. Не уходят UUID пользователя, сырые события, решения, скрытые тесты. Текст цели может содержать введённые пользователем персональные данные: интерфейс предупреждает об отправке.
- Прочтение материала не доказывает знание; infrastructure_error не считается ошибкой ученика. BERT для этого среза не нужен: агрегирование кодом и восстановление карточек по ID экономят токены без отдельной модели.
- Текст AI-цели не сохраняется в БД; сохранение цели практики сохраняет темы и темп. Повторное посещение автоматически строит обычный план. Для AI пользователь явно вводит цель и запускает подборку.
- Бесплатные API не дают гарантии доступности. Смена провайдера использует его отдельную разрешённую квоту; смена ключа того же проекта не увеличивает квоту.

## Ключи и обычные чаты

Автоматизируется получение списка моделей и переключение настроенных ключей. Создание ключа требует аккаунта и разрешений владельца; поиск чужих ключей не является способом интеграции. Бесплатный веб-чат и API — разные продукты и лимиты. Сайт работает через официальный API; сессии браузера и автоматизация обычных чатов здесь не используются. Ключи хранятся только на сервере, не в frontend и не в чатах.

## План из одной текстовой цели

На `/practice` новый блок «От цели к учебному плану» вызывает `learningPlan`:
AI выбирает до пяти активных тем (просматривается до 200) и до восьми материалов
из 12 редакционных карточек. Затем gateway получает актуальную практику по темам
без второго AI-запроса. Кеш выбора тем не кеширует историю решений: практика
пересчитывается при каждом запросе. Материалы — внешние ссылки, не документы content.
Их длительность — оценка первого упражнения, не полного курса; время практики отдельно.
Пробелы практики видны по каждой теме. Ничего не найдено и недоступность AI различаются.

Готовый план можно сохранить в PostgreSQL и открыть через «Мои планы».
Статусы материалов сохраняются отдельно от доказанного решения задач; чтение
не считается освоением темы. Сохранённый план обновляется по явной кнопке.

В `/admin/collected-tasks` добавлен поиск официального каталога Codeforces по
названию и тегам. Кеш каталога — 30 минут, сбой — пауза одну минуту, максимум 20
результатов. Кнопка отправляет URL в существующую очередь импорта; публикация
происходит после модерации. Для широкого поиска в плане есть ссылка DuckDuckGo;
HTML-скрейпинга поисковой выдачи нет. Новые API-ключи для этого не нужны.


## Сохранённые планы и доступ

- Новые планы приватны. Владелец включает доступ по ссылке; публичный ответ
  содержит цель/материалы/задачи без личных отметок и истории.
- Клонирование создаёт независимый приватный план. Отметки материалов сброшены;
  успешные решения нового владельца учитываются отдельно.
- Материалы: TODO, IN_PROGRESS, DONE. Общий процент — завершённые пункты / все
  пункты, без весов и без утверждения об уровне знаний. Успех другой версии задачи
  подписан явно; при недоступной/усечённой истории общий процент не показывается.
- Refresh сохраняет имеющиеся шаги и отметки и добавляет новые. Завершённые материалы
  исключены из AI-выбора. Явно убранные задачи не возвращаются при обновлении.
- Изменения используют revision; устаревший запрос получает CONFLICT, а не затирает
  другую вкладку. Список содержит до 50 кратких планов, детали загружаются отдельно.
- Миграция: 202611140001_saved_learning_plans.sql. Для компонентного теста нужна
  выделенная SAVED_PLANS_TEST_DSN с применёнными миграциями; Docker не стартует из теста.
